# alphabet-soup

Word-search solver for the Alphabet Soup challenge.

## Run

```bash
python main.py <input-file>
```

Input format:

```text
<rows>x<cols>
<grid row 1 with spaces>
...
<grid row N with spaces>
<word 1>
<word 2>
...
```

Output format:

```text
<word> <start_row>:<start_col> <end_row>:<end_col>
```
